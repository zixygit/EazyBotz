## ✨ Features

| Category | What it does |
|----------|--------------|
| 🧑‍💼 **User Management** | Kick, ban, timeout, and manage members with ease |
| ⚖️ **Moderation** | Full suite of moderation commands to handle any situation |
| 🛡️ **Server Protection** | Guardrails and protections that keep your community secure |
| 🚫 **Anti-Abuse** | Built-in safeguards against spam, harassment, and rule-breakers |

> More features are on the roadmap — this is just the beginning.

## 📦 Getting Started

### 1. Invite the bot
Add **Gatekeeper** to your server and grant it the necessary permissions.

### 2. Configure your server
Set up moderation roles and permissions the way *you* want them.

### 3. Command it
Use the moderation suite right away. No complicated setup, no bloat.

## 🧠 Second Brain

This repo is also home to the **Second Brain** — a personal AI-powered knowledge system that lives in [`/Second Brain`](Second%20Brain/).

> **"Every note must be linked, or it doesn't exist."**

A vault-based system built around three operating roles:

- 🏋️ **Coach** — teaches through practice, not lectures. Summarizes, challenges, and builds your career.
- 🗂️ **Chief of Staff** — keeps the vault organized, tracks people/projects/decisions, and points you at the highest-leverage task.
- 🤝 **Accountability Partner** — firm, no excuses. "You said X by Y. It's Y. What happened?"

Backed by three core documents:
